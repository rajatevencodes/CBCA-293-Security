# CBCA293 Project Requirements (Essentials Only)

**Course:** CBCA293 Security and Privacy for Big Data Analytics
**Programme:** BCA, 3rd Year, 6th Semester, Bennett University (SCSET)

This file merges the two university documents (the milestones and rubric document, and the report template), with duplicates removed. It keeps only what this project needs. Parts that do not apply to our chosen track (Spark MLlib, Databricks, Hadoop, Hive, Pig, Kerberos, Ranger) are left out.

## 1. Team

* You can work alone, or in a team of up to 4 students from the same Big Data Lab batch.
* Evaluation happens in the lab, batch by batch.

## 2. Chosen Track: Tableau Dashboard

The brief says:

* Do data visualization and analysis in Power BI **or Tableau**.
* Build a high-quality, **interactive dashboard** on at least **one relevant dataset**.
* It must include **charts, graphs, filters, slicers and KPIs**.
* It must show **clear data storytelling**, a **proper layout** and **meaningful interpretation**.

## 3. Milestones

| Milestone | Marks | When | Deliverables | Graded on |
|---|---|---|---|---|
| **M1:** Research definition and planning | 12 | 1 to 10 Oct 2026 | Report **Chapters 1 and 2**, minimum 10 to 15 pages | Problem Analysis, Project Design |
| **M2:** Final report, demo and presentation | 18 | 15 Oct to 5 Nov 2026 | Report **Chapters 3 to 5** with screenshots, a **15-minute presentation**, a **live demo**, full **source code** with a README and inline comments, and the **dataset files** | Implementation, Report, Communication |

* **Total:** 30 marks, scaled down to **10% of the course grade**.
* **LMS submission:** the complete package is uploaded after the viva. The brief gives the LMS deadline as "20 April 2026", which is a typo. Confirm the real date with your faculty.

## 4. LMS Submission Checklist

1. Complete report, Chapters 1 to 5
2. All dataset files
3. Complete source code
4. Screenshots of results and outputs
5. Plagiarism report (Turnitin)
6. Any supporting files

| Similarity | Level | Marks |

## 6. Rubric (30 marks = 10 sub-criteria × 3 marks)

Scale: Excellent 3, Good 2, Acceptable 1, Poor 0. The table shows what "Excellent" requires.

| Criterion | Sub-criterion | To score 3 (Excellent) |
|---|---|---|
| Problem Analysis | Problem domain identification and analysis | Clearly identified, in-depth analysis, strong justification |
| Problem Analysis | Review of existing systems and feasibility | Comprehensive review, clear feasibility analysis |
| Project Design | Objectives and methodology | Clear, **measurable** objectives, well-defined methodology |
| Project Design | Relevance of algorithms and techniques | Highly relevant and well justified |
| Implementation | Design and implementation in sync | Fully aligned and consistent |
| Implementation | Modules implemented and demonstrated | All modules correct and demonstrated |
| Report | Organization and structure | Well organized, logical, easy to follow |
| Report | Compliance with the report format | Fully follows the format in section 7 |
| Communication | Presentation clarity | Clear, confident, well structured |
| Communication | Contribution by each member | All members contributed equally |

## 7. Required Report Format

### Front matter (in this order)
